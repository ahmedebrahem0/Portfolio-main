## Selected projects

### [YUMA Furniture](https://yuma-homz.com) — live commerce

A Next.js storefront serving real customers. My work covers OTP authentication, guest and customer carts and wishlists, RTK Query data flows, reusable SEO metadata, and error handling across live releases.

### [El-Hattab Furniture](https://el-hattab.com) — Arabic commerce

An Arabic, right-to-left furniture storefront covering product discovery, account flows, and checkout. I organized the frontend by feature and built responsive screens, OTP login, API integration, forms, and SEO metadata.

### [Truck Expenses & Trip Settlement System](https://cach-system.vercel.app/dashboard) — used in a real trucking workflow

A mobile-oriented Arabic application for recording trips, freight charges, advances, categorized expenses, debts, company settlements, driver earnings, and assistant wages. It includes monthly financial reports, CSV export, print support, destination rates, and validated JSON backup and restore. Data is stored on the device through **Dexie and IndexedDB**. A truck driver currently uses the application. [View source](https://github.com/ahmedebrahem0/CachSystem.git).

The locally developed fuel-spending comparison report is still awaiting release, so it is not presented as a shipped feature. The application does not claim cloud sync, multi-user authentication, or measured fuel consumption.

### [Logistics & Shipping Management System](https://shipping-system-nine.vercel.app/) — operations platform

A logistics interface with distinct Admin, Employee, Merchant, and Delivery experiences. It models an order lifecycle, role-based permissions, dynamic forms, and analytics dashboards. [View source](https://github.com/ahmedebrahem0/shipping_system).

### [EduSystem](https://school-system-liard-one.vercel.app/login) — school management

A school administration interface for Admin, Teacher, and Student roles, including classes, attendance, grades, timetables, and analytics. [View source](https://github.com/ahmedebrahem0/School_System).

### [FreshCart](https://ahmedebrahem0.github.io/FreshCart/Home) — React commerce

An e-commerce application with product browsing, authentication, cart interactions, and payment flows. [View source](https://github.com/ahmedebrahem0/FreshCart).
